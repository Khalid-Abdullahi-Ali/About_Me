## 🟣 About Me

<div align="center">

I'm **Khalid Abdullahi**, a final-year **BSc Cybersecurity & Networking** student at **ISBAT University, Kampala**, maintaining a **~3.9 GPA** while building toward a career as a **Security Engineer specialized in Vulnerability Assessment & Penetration Testing (VAPT)**.

I design and break systems in equal measure — deploying SIEM platforms and secure network architectures on one side, and running controlled exploitation labs (web app pentesting, wireless attacks, Active Directory attack paths) on the other. I also build the tooling around security work itself, using Python, Flask, and React to turn raw packet and log data into usable dashboards.

Fluent in **English, Kiswahili, and Somali**, and driven by one principle:

> *"Understand the network. Build the system. Test the security."*
